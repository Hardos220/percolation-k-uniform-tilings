# Site and bond percolation thresholds of all k-uniform tilings with k ≤ 10

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23533708.svg)](https://doi.org/10.5281/zenodo.23533708)

Code and data for the paper *Site and bond percolation thresholds of all k-uniform tilings with k ≤ 10* by
Maksim Elisov (Samara National Research University), submitted to Physical Review E.

## Results

- Site and bond percolation thresholds of all 23,396 k-uniform tilings of the plane by regular polygons with
  k ≤ 10 (46,792 thresholds), for the tilings of the catalog of Čtrnáct and Kopczyński
  ([zenorogue/tes-catalog](https://github.com/zenorogue/tes-catalog), commit `6772c7c6`), whose counts
  11, 20, 61, 151, 332, 673, 1472, 2850, 5960, 11866 agree with OEIS [A068599](https://oeis.org/A068599).
- k ≤ 4 (243 tilings): three tori per threshold and finite-size extrapolation, median uncertainty 3×10⁻⁶;
  the 22 Archimedean reference values are reproduced with an rms deviation of 0.71 standard errors, and
  the unpublished bond thresholds of the 20 two-uniform lattices (Gu and Ziff) with χ² = 19.5 for 20 values.
- k = 5–10: one torus per threshold, statistical uncertainties 2–7×10⁻⁵; a check of 260 thresholds on
  near-square tori with about four times as many sites (random tilings, elongated tori, large cells, and the
  tilings with the largest square domains) shows no finite-size bias at this level.
- Code check: on 12 small tori the Monte Carlo distributions of the wrapping and cross occupation numbers agree
  with full enumeration (24 χ² tests), and so do the roots of the threshold condition.
- Empirical rules (Euler-characteristic estimate, Galam–Mauger, Lebrecht et al., Scher–Zallen) tested on the
  full set; a linear rule in the vertex-type fractions predicts the thresholds to about 2×10⁻³.
- Slip pairs: tilings that differ only by the registry of strips; the threshold difference decays
  exponentially with the distance between the strips.

The thresholds are in [`results/tables/all_thresholds.csv`](results/tables/all_thresholds.csv) and, with the
periodic graphs of all tilings, in the Supplemental Material archive
[`paper/supplemental/supplemental_material.zip`](paper/supplemental/supplemental_material.zip)
(see [`paper/supplemental/README.txt`](paper/supplemental/README.txt) for the columns).

## Method in brief

Microcanonical Monte Carlo (Newman–Ziff) on L_x × L_y tori of unit cells. For each sample the code records the
number of occupied sites (bonds) at which a cluster first wraps the torus and at which a cluster first wraps in
two independent directions (a cross configuration). The finite-size estimate p_N is the root of
R_e(p) + R_x(p) = 1, i.e., P(no wrapping) = P(cross), which needs no knowledge of the torus anisotropy.

## Layout

| Path | Contents |
|---|---|
| `tools/fetch_catalog.sh` | downloads the k-uniform part of the catalog (k = 1–10) at the commit used |
| `tiling/` | `.tes` → periodic graph (`tes2cell.py`, `parse_many.py`), export to the simulation input (`export_cells.py`) |
| `nz/nz.c` | Newman–Ziff simulation with wrapping and cross detection (C); `nz/exact.c`: exact enumeration on small tori |
| `gpu/nz_gpu.cu` | data-parallel version of the same algorithm (CUDA; also compiles as C++ on a CPU) |
| `run/` | job-list generators and the job lists used (with seeds); `batch.py` runs a job list in parallel |
| `analysis/` | estimators, finite-size fits, tables, statistics, transfer matrices, figures, Supplemental Material |
| `results/` | processed results: threshold table, core report, summaries of all checks |
| `reference/` | reference values used for validation (Archimedean thresholds from the primary sources cited in the paper; site thresholds of Neher et al. for the 2-uniform lattices) |
| `paper/` | LaTeX source (REVTeX 4.2), tables, figures, Supplemental Material |

## Requirements

- Python ≥ 3.10 with numpy, scipy, matplotlib, networkx;
- a C compiler (e.g. `cc -O3 -march=x86-64-v2 -o nz/nz.exe nz/nz.c -lm`); the job runner calls `nz/nz.exe`;
- optional: CUDA (`nvcc -O3 -arch=sm_80 -o gpu/nz_gpu gpu/nz_gpu.cu`), nauty's `labelg` (set `LABELG`) for
  `analysis/matching_iso.py`, and a LaTeX engine (e.g. tectonic) for the paper.

Parallel scripts read the number of worker processes from the environment variable `RMQ_CPU` (default 1).

## Reproducing

1. Tilings → periodic graphs:
   ```bash
   bash tools/fetch_catalog.sh
   python tiling/tes2cell.py data/cells data/tes/01/*.tes data/tes/0[2-4]/*/*.tes      # k <= 4, with symmetry checks
   RMQ_CPU=8 python tiling/parse_many.py data/cells data/cells_txt data/tes/0[5-9] data/tes/10   # k >= 5
   python tiling/export_cells.py
   ```
2. Simulations. Every job line is `cell mode Lx Ly cpu_seconds seed outfile`, e.g.
   `RMQ_CPU=8 python run/batch.py run/jobs_atlas_c00.txt`. The atlas (k ≥ 5) uses `run/jobs_atlas_c*.txt` and
   the second round `run/jobs_atlasr1_c*.txt`; the core (k ≤ 4) tasks are generated by `run/make_core_tasks.py`
   and were run with `gpu/nz_gpu.cu`; further lists: finite-size study (`jobs_fss.txt`), slip pairs
   (`jobs_slip_hp*.txt`), atlas check (`jobs_atlas_check.txt`; square-domain stratum: `make_atlas_check_sq.py`,
   `jobs_atlas_check_sq_*.txt`). Runs are limited by CPU time, so the number of
   samples, not the results, depends on the machine.
3. From the raw histograms to the tables (needs the outputs of step 2, about 330 MB: release assets and the
   Zenodo record, see below):
   `analysis/core_report.py`, `analysis/build_tables.py`, `analysis/atlas_rounds.py`, `analysis/atlas_check.py`,
   `analysis/slip_hp_summary.py`.
4. From the processed results in `results/` (stored here) to the paper: `analysis/paper_tables.py`,
   `analysis/paper_stats.py`, `analysis/paper_rules.py`, `analysis/review2_checks.py`, `analysis/review3_checks.py`,
   `analysis/review4_checks.py`,
   `analysis/periodic_checks.py` (exact symmetry groups, k orbits and pairwise non-isomorphism of all periodic
   graphs; needs `data/cells`), `analysis/local_hierarchy.py 3 6 site` and `... bond` (local descriptors; needs
   `data/cells`),
   `analysis/band_tm_nc.py 12` and
   `analysis/band_tm_nc.py 12 --p bond=0.5,site=0.5927 --out results/band_tm_nc_plimit.json`, `analysis/paper_figs.py` (the tiling figures need `data/cells` from step 1),
   `analysis/make_supplement.py`; then compile `paper/main.tex`. The arXiv bundle is built by `tools/make_arxiv.py`.
5. Coupled runs of slip pairs: `analysis/slip_coupled_cells.py` (cells with a common numbering), `nz/nz_pair.c` or
   `gpu/nz_pair_gpu.cu` (task lists `run/jobs_slip_coupled_gpu.txt`, `run/slip_coupled.py` for CPU runs),
   `analysis/slip_coupled_summary.py`; extra core runs: `analysis/core_extra.py`.
6. Exact test on small tori: `RMQ_CPU=8 python analysis/exact_check.py 100000000 20` (needs `nz/exact.exe`
   and `nz/nz.exe`; Monte Carlo against full enumeration).

Raw histograms: `raw_core.tar.gz` and `raw_atlas.tar` are attached to release v1.1, the updated
`raw_checks.tar.gz` (all checks, including the small-torus test) to release v1.3; all of them are in the Zenodo
record [doi:10.5281/zenodo.23533708](https://doi.org/10.5281/zenodo.23533708), format in `RAW_README.txt`.
